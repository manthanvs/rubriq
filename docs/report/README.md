# Report

The institute-template report document goes here (`.docx` and its exported
`.pdf`), assembled from the eight documents in [`../`](..) in the order given
in [`../README.md`](../README.md#report-assembly).

Nothing is generated into this directory. It exists so the repository layout
matches §9 of the specification and so the finished artifact has an obvious
home next to the material it was written from.
